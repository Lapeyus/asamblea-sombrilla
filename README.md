# asamblea.kerewes.com

Página sombrilla del proyecto de análisis de las actas del Plenario de la
Asamblea Legislativa de Costa Rica.

**Este repositorio es un destino de publicación, no una fuente.** El contenido
se genera desde `scripts_sombrilla.py` en el repositorio del pipeline y se
publica aquí automáticamente en cada cambio. Editar `index.html` a mano no
sirve de nada: el siguiente despliegue lo sobrescribe.

Los paneles por periodo constitucional no viven aquí — cada uno se despliega
como su propio servicio en Cloud Run y se enlaza desde esta página.
